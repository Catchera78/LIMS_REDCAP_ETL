Pipeline LIMS → REDCap

Fiche d'explication et d'exécution pas à pas — de l'extraction Excel du LIMS au fichier prêt pour l'import REDCap.

Version 1.0 Public : Data Manager & équipe labo Poste Windows

Le pipeline transforme automatiquement une extraction Excel du LIMS en fichier compatible REDCap, avec un rapport qualité. Il remplace le nettoyage manuel + do-file Stata. Il n'importe pas dans REDCap. Un contrôle humain reste obligatoire avant l'import.

Flux Le principe

Excel LIMS→ ETL automatique→ Contrôles QC→ Ready_Data + rapport QC→ Validation humaine→ Import REDCap

1 Exécuter — en 3 gestes

  1. 1

    Déposer l'extraction

    Exporter l'onglet Résultats des Analyse en .xlsx et le placer — un seul fichier — dans le dossier input/. Aucun nettoyage manuel (en-têtes, légendes) n'est nécessaire.

  2. 2

    Lancer

    Double-cliquer sur RUN_LIMS_REDCAP.bat. Une fenêtre s'ouvre et reste ouverte à la fin.

  3. 3

    Lire le tableau de bord, puis le rapport QC

    Vérifier le STATUS (ci-dessous), puis ouvrir output/QC_Report_<date>.xlsx avant tout import.

2 Les trois statuts

READY

0 erreur, 0 avertissement. Ready_Data produit. Vérifier le QC puis importer.

READY_WITH_WARNINGS

Pas d'erreur bloquante, mais des avertissements. Ready_Data produit — examiner les avertissements avant d'importer.

NOT_READY

≥ 1 erreur bloquante. Fichier nommé NOT_READY_Data (jamais Ready_Data). Corriger, puis relancer.

3 Fichiers produits

output/Ready_Data_<date>.csvLe fichier à importer dans REDCap — 45 colonnes, UTF-8, séparateur ;.
output/QC_Report_<date>.xlsxRapport qualité, 8 feuilles : SUMMARY · SCHEMA · ERRORS · WARNINGS · UNKNOWN_VISITS · UNKNOWN_COLUMNS · DUPLICATES · MAPPING.
archive/<date>/Copies horodatées : raw/ (original, jamais modifié) · output/ · qc/ · logs/.

Une valeur source vide reste vide sans erreur ; seule une valeur non vide non reconnue est signalée. Chaque ligne du QC indique source_row, patid et source_value.

5 Dépannage express

SituationSolution
« Aucun fichier .xlsx dans input »Déposer l'extraction dans input/
« Plusieurs fichiers .xlsx »N'en laisser qu'un
Structure FAILColonne obligatoire absente (ex. ID de Participant) — vérifier l'export LIMS
Structure WARNINGColonne déplacée / nouvelle — non bloquant, voir SCHEMA
Note « openpyxl absent »Non bloquant — pip install -r requirements.txt

Les règles métier sont éditables au tableur dans config/*.csv — sans toucher au code. Journal détaillé : archive/<date>/logs/run_<date>.log.

6 Avant d'importer dans REDCap

  • Statut READY ou READY_WITH_WARNINGS (jamais un NOT_READY_Data).
  • Feuille ERRORS du QC vide.
  • Feuilles WARNINGS / DUPLICATES revues : répétitions légitimes.
  • Feuille UNKNOWN_VISITS vide (sinon compléter le mapping).
  • Nombre de Records output cohérent avec l'attendu.
  • Fichier LIMS original bien archivé (archive/<date>/raw/).
